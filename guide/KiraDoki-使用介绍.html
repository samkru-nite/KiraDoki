认识小岛

小岛由两颗胶囊组成：右边的大胶囊显示一件最值得你看的事；左边的小胶囊里，每个小图标是另一件正在发生的事。

点大胶囊 = 掀起卡片

大胶囊会像一张纸一样掀起来，变成一张完整的卡片：更多文字、进度、按钮（打开对话、在文件夹中显示、上一首 / 下一首……）。点卡片外面任何地方就收回去。

点小图标 = 换上来

小图标和大胶囊互换位置，那件事就到大胶囊上了。

 圆球

左键：列出所有卡片（小胶囊放不下的也在这里）。右键：快速计时器、番茄钟、秒表、设置。

右键大胶囊 / 小图标

置顶：一直占着大胶囊。收起：只留小图标，不再跳出来打扰。关闭：这件事不看了。

颜色只有三种意思

橙色 = 需要你处理（AI 在等你、缺纸、电量快没了……） 绿色 = 做完了（AI 完成、下载完成、复制完成……） 红色 = 出错了（AI 出错停止、U 盘弹出失败……）

大胶囊用一圈细边框表示颜色，小图标直接变色。没有颜色 = 正常进行中，不用管它。

重点功能 ①

AI 在干什么，一眼就知道

让 Claude 或 ChatGPT 写代码、跑任务的时候，你可以去干别的。它需要你或者做完了，小岛会马上告诉你；点一下 ↗ 就跳回那个对话。

演示：一个任务从开始到完成
状态小岛上是什么样
工作中Claude 的标志 + 它正在说的话（一句一句换）。
等你橙色边框 + 对话名。它在等你批准权限或回答问题，会一直留着直到你处理。
完成绿色边框 + 最终回复的第一句 + ↗ 按钮，点了跳回那个对话。
停止 / 中断写明原因：需要重新登录、请检查套餐、服务器繁忙、因错误中止、用量已达上限（几点重置）。

Claude Code / Claude 应用

命令行、VS Code 里的 Claude Code 和 Claude 桌面应用都支持。第一次需要"连接"：安装时勾上"连接 Claude Code 通知"，或者之后在 设置 → 通用 里点连接（小岛上也会出现一张"点击连接"的卡片）。

ChatGPT 应用（Codex）

不用连接，装上就能看到它的工作中 / 等你 / 完成。

掀起来看回答

点大胶囊掀起卡片，能看到它最后的回答（标题、列表、代码都排好版）或者正在做的那一步，不用切过去就知道结果。

合上盖子它也继续

设置 → 通用里打开"合盖时让 AI 继续工作"：AI 在工作或等你时合上笔记本不会睡眠，做完自动恢复你原来的设置。还可以"合盖时切到最佳能效"——AI 在云端思考，省电几乎不拖慢它。（合盖后电脑还在运行，别马上塞进包里，会发热。）

好几个对话一起跑

每个对话一张卡片，同时进行也不会混。哪个刚有变化，哪个就上大胶囊。

重点功能 ②

中转站：文件先放这儿

要把文件拖到一个被挡住的窗口？要从好几个文件夹里凑一堆文件？先把它们拖到小岛上放着，想用的时候再从小岛上拖出去。

演示：拖进中转站，再拖到别的文件夹
  • 放进去：把文件 / 文件夹拖到小岛附近松手就行（拖动时小岛会准备接住）。中转站只记住"文件在哪"，不会复制一份，不占空间。
  • 拿出来：按住大胶囊拖出去 = 全部拿走；掀起卡片能看到文件列表，每一行都可以单独拖出去，也能像资源管理器一样单击、Ctrl、Shift 多选。
  • 复制还是移动跟 Windows 一样：同一个盘移动、不同盘复制；松手时按住 Ctrl 是复制，按住 Shift 是移动。拖完会告诉你"已复制 / 已移动"。
  • 文件被移走了会自动从中转站去掉；在列表里点  或"清空"只是从中转站移除，不会删除文件。
  • 复制文件或图片时，复制提示卡片上有  按钮，点一下直接加入中转站（复制的图片会先存成文件）。
  • 关机重启后，中转站里的东西还在。
重点功能 ③

下载、复制、压缩、导出……进度都在这

费时间的文件活儿开始后，你就可以去忙别的。有百分比的会显示进度条和剩余时间；做完了绿色提醒，还能一键"在文件夹中显示"。

点大胶囊看掀起后的样子
浏览器、迅雷、夸克会自动找到它们的下载位置。用别的下载软件的话，在 设置 → 下载和文件 里把它的下载文件夹"添加"进去。每一项都能在设置里单独关掉。
重点功能 ④

正在播放

网易云、QQ 音乐、Spotify、Windows 自带的媒体播放器……放歌时小岛显示歌名和封面，旁边的音乐条跟着声音跳。掀起来能看进度、上一首 / 暂停 / 下一首。

点大胶囊掀起
  • 一个播放器一张卡片；暂停超过 5 分钟或者关掉播放器，卡片自己消失。
  • 浏览器里放的视频和音乐默认不显示（不然刷网页时太吵），要的话在 设置 → 音乐 里打开。
  • 进度条要播放器自己报告，有的不报（比如网易云），那就只显示歌名。
我的播放器不显示？播放的时候按 Win + A，看快速设置最下面有没有一张媒体卡片。有 → 小岛就能显示；没有 → 这个播放器没把"正在播什么"告诉 Windows，小岛也读不到。例如 PotPlayer 要 2024 年 6 月（240618）以后的版本才支持，微软商店里那个是 2021 年的旧版，需要去官网下载新版。
重点功能 ⑤

计时器、番茄钟、秒表

右键圆球就能开始：几个常用时长的快速计时器、番茄钟、秒表。图标上的指针会真的转，时间到了响一声。

右键圆球打开菜单 · 点大胶囊掀起
  • 快速计时器：默认 5 分钟、25 分钟，可以在 设置 → 计时器 里增删，最多 6 个。
  • 番茄钟：默认专注 25 分钟、休息 5 分钟，专注 4 轮后长休息 15 分钟；这几个数字都能改。
  • 可以同时开好几个计时器，每个一张卡片。掀起卡片能暂停、继续、再来一次。
  • 玩全屏游戏、看全屏视频时可以让提示音静音（设置里的开关）。
重点功能 ⑥

日历：下一节课还有几分钟

把 Google 日历（或任何能给出 iCal 地址的日历）加进来，日程快开始时小岛开始倒数，开始、进行中、结束都会告诉你。

  • 1 小时以内每分钟往下数（"10分钟后 高数"），更远的写时间（"14:00""明天8:00""周三8:00"）。
  • 日程自己设了提醒才会提前提醒（橙色）；如果提醒是"开始时"，开始那一刻橙色卡片会一直留着，等你亲手关掉。
  • 两个日程撞在一起时多出一张卡片，各管各的。
  • 每 10 分钟自动同步一次，可以加好几个日历。
怎么添加 Google 日历：网页版 Google 日历 → 设置 → 左边点你的日历 → "集成日历" → 复制 "iCal 格式的私密地址" → 粘贴到 设置 → 日历 → 添加日历。这个地址相当于钥匙，别发给别人；加进来后设置里只显示日历名，不再显示地址。

消息和系统提醒

不那么重要、但知道一下更安心的事。它们只出来几秒，或者安静地待在小图标里。每一类都能在 设置 → 提醒 里单独关掉。

小规则

卡片怎么来、怎么走

  • 亮相：新的事先在大胶囊上停一会儿（一般 2 秒），然后收进左边的小图标。同时来好几件就排队，一件一件亮相。
  • 最近有动静的上大胶囊：哪件事刚变了（比如 AI 从工作中变成完成），它就到大胶囊上；你点过的也算。
  • 鼠标放在胶囊上时不换：你正在看的那张不会被别的抢走。
  • 只亮一下的提醒（复制、蓝牙、网络……）2–10 秒后自己消失；需要你处理的（橙色）一直留着，直到你处理或关掉。
  • 小胶囊放不下的小图标不会丢，点圆球就能在列表里看到全部。
  • 掀起卡片或打开列表时，大胶囊会稍微变暗，告诉你"焦点在上面"。

开始用

安装和第一次打开

  1. 双击 KiraDoki-Setup-0.1.0.exe。不需要管理员权限，也不用另外装 .NET 之类的东西。
  2. 如果出现蓝色的"Windows 已保护你的电脑"：点 更多信息 → 仍要运行。这是因为程序没买数字签名证书，不是病毒。
  3. 安装时有两个选项：登录时启动 KiraDoki（推荐勾上）；连接 Claude Code 通知（用 Claude Code 就勾）。
  4. 装完小岛就出现在任务栏最左边。位置不喜欢就去 设置 → 通用 改。

卸载：Windows 设置 → 应用 → 已安装的应用 → KiraDoki → 卸载。卸载会把 Windows 通知横幅恢复原样、断开 Claude Code 连接；你的设置会保留，重新安装还能接着用。

常见问题

常见问题

支持哪些电脑？

Windows 11，64 位（x64）。Windows 10 和 ARM 电脑（比如骁龙笔记本）暂时不支持。

小岛不见了？

任务栏上图标太多、放不下时小岛会自动藏起来。关几个任务栏图标，或者把位置换成"正中间"。设置 → 关于 → 诊断 里能看到"嵌入任务栏"是正常、浮在任务栏上，还是放不下已隐藏。

会不会偷看我的东西、上传数据？

不会上传。所有判断都在你的电脑上完成。为了显示通知，它会读取 Windows 通知的内容（设置里写明了，可以关掉）；读不到通知时会自动把 Windows 自己的通知横幅还给你，不会让你漏消息。日历只会去下载你自己填的那个日历地址。

我不用 Claude / ChatGPT，有用吗？

有。下载进度、中转站、音乐、计时器、日历、消息和系统提醒都和 AI 无关。设置里把 AI 的开关关了就行。

QQ / 微信消息能显示吗？

QQ 发的是 Windows 通知，会变成小岛上的卡片，点"打开"会把 QQ 窗口调出来。微信不发通知，只会让任务栏图标闪烁——小岛会认出这个闪烁，显示"新消息"，单独打开的聊天窗口还会显示聊天名。

它会不会很耗电、拖慢电脑？

平时几乎不占资源。动画跟随 Windows 的"动画效果"设置：在 Windows 设置 → 辅助功能 → 视觉效果 里关掉动画，小岛也会安静下来。

出问题了怎么反馈？

设置 → 关于 → 诊断 → "复制日志"，把复制的内容连同你看到的情况（最好有截图）发给作者。
